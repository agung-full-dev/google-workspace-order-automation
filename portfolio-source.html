Automation workflow

The script handles the repetitive steps.

The workflow is short enough to understand and careful enough to avoid duplicate events.

01

Order entered

The team adds cake, payment, and schedule details.

02

Data checked

Required fields and the due date are validated.

03

Status confirmed

Only confirmed orders are ready for calendar sync.

04

Event synced

The script creates or updates the linked event.

05

Result logged

The order ID, result, and details are saved.

Required-field checks

Incomplete orders stop before a bad event is created.

Duplicate prevention

A saved event ID keeps later changes on the same event.

Clear sync log

Created, updated, and skipped results are recorded.

Easy configuration

Sheet names, calendar, and headers are kept in one config.
