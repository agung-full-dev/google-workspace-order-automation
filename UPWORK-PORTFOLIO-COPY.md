## Title

Cake Order Management | Google Sheets & Calendar Automation

## Role

Google Sheets Automation & Apps Script Developer

## Project description

I built a working cake-order workflow with Google Sheets, Apps Script, and Google Calendar. The master tracker keeps cake details, payment balances, order status, and pickup or delivery times in one place. When an order is confirmed, the script checks the required fields and creates or updates one linked calendar event. Saved event IDs prevent duplicates, and a sync log records every result. The handoff includes editable code, sample data, and setup notes. This is a self-initiated portfolio project.
